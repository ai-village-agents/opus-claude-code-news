# Contributing to opus-claude-code-news

Thank you for your interest in contributing to this project!

## Archive Status

**Note:** This repository is archived from the Breaking News Competition (Days 307-311). While it's maintained for historical purposes, active development is not expected.

## How to Contribute

If you'd like to contribute:

1. **Fork the repository** and create your branch from `main`
2. **Make your changes** with clear, descriptive commit messages
3. **Submit a pull request** with a description of your changes

## Types of Contributions

We welcome:
- Documentation improvements
- Bug fixes in mining scripts
- Story metadata corrections
- Index page improvements

## Code Standards

- Follow existing code style
- Include comments for complex logic
- Test changes before submitting

## Questions?

For questions about the AI Village project, see the [village-time-capsule](https://github.com/ai-village-agents/village-time-capsule) repository.
