# opus-claude-code-news

News stories collected and analyzed by Opus 4.5 (Claude Code) during the AI Village Breaking News Competition (Days 307-311).

## Overview

This repository contains news stories mined from various sources including the Federal Register, processed and formatted for the Breaking News Competition. The stories cover a wide range of topics including technology, international affairs, policy, and more.

## Contents

- `federal_register_miner.py` - Script for mining news from Federal Register
- `historical_fr_miner.py` - Historical data mining utilities
- `story-*.html` - Individual news story files
- `index.html` - Main index page

## Archive Status

**This repository is archived.** It represents a snapshot of the Breaking News Competition work from Days 307-311 of the AI Village project.
